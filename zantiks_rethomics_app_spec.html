Zantiks-to-Rethomics Analysis App Specification

Comprehensive Functional & Technical Design Specification Document

Version 1.0.0 • R Shiny Architecture

1. System Overview & Objective

This application automates data transformation and behavioral genetics analysis for circadian rhythm researchers using Zantiks MWP / multi-well systems.

  • Module 1 (Data Converter): Converts raw Zantiks CSV output into 42-column standard Drosophila Activity Monitor (DAM) tab-separated text format (DAM_file.txt).
  • Module 2 (Analysis Studio): Links DAM files with experimental metadata (metadata.csv) and runs Rethomics packages (behavr, damr, sleepr, zeitgebr, ggetho) for sleep, activity, actograms, and circadian rhythmicity.

2. Input Schemas & Formats

2.1 Raw Zantiks CSV Format

Skipped metadata lines in rows 1-4 contain start timestamp. Column headers at row 5 contain RUNTIME, UNIT, TEMPERATURE, L_OR_D, DAY, HOUR, TIME_BIN, and well channels A1 to D6.

2.2 Standard 42-Column DAM File Format

Column Range Field Name Data Type Description
Col 1 Index Integer 1 to N row sequence number
Col 2 Date String Formatted date e.g., 01 Aug 25
Col 3 Time String Formatted time HH:MM:SS
Col 4 Status Integer Light status (1 = Light, 0 = Dark)
Cols 5–10 Flags & Temp Integer System status flags (default 0)
Cols 11–34 Channels 1–24 Integer Scaled movement counts: round(distance * 1000)
Cols 35–42 Channels 25–32 Integer Zero-padded unused channels

2.3 Experimental Metadata Schema

3. Data Transformation Logic

# Data Transformation Core Algorithm (Zantiks CSV -> DAM Text)
convert_zantiks_to_dam <- function(input_csv, output_txt, scale_factor = 1000) {
  start_dt <- parse_zantiks_datetime(read_first_line(input_csv))
  raw_df <- fread(input_csv, skip = 4)
  
  timestamps <- start_dt + raw_df$RUNTIME
  date_formatted <- strftime(timestamps, "%d %b %y")
  time_formatted <- strftime(timestamps, "%H:%M:%S")
  
  act_cols <- names(raw_df)[grep("^[A-D][1-6]$", names(raw_df))]
  scaled_act <- round(as.matrix(raw_df[, ..act_cols]) * scale_factor)
  
  complete_dam <- cbind(
    Index = 1:nrow(raw_df),
    Date = date_formatted,
    Time = time_formatted,
    Status = ifelse(raw_df$L_OR_D == "LIGHT", 1, 0),
    scaled_act_pad32
  )
  write.table(complete_dam, output_txt, sep = "\t", quote = FALSE, row.names = FALSE, col.names = FALSE)
}

Statistical Test Suite

  • Non-Parametric 2-Group: Wilcoxon rank-sum test (Mann-Whitney U)
  • Multi-Group: Kruskal-Wallis test
  • Rhythmicity Criteria: Chi-Square periodogram peak power vs significance threshold
