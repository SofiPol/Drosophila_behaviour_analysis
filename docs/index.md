# Drosophila Behaviour Analysis

This repository provides tools for analysing *Drosophila* behaviour data from Zantiks systems using the Rethomics framework.

## Features

- **Data Conversion**: Convert raw Zantiks CSV output to standard DAM (Drosophila Activity Monitor) format.
- **Analysis & Visualisation**: Link converted DAM files with experimental metadata and run a full analysis pipeline using [Rethomics](https://rethomics.github.io/).
